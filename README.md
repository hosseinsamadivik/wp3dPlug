# پیکربندی چاپ سه‌بعدی برای ووکامرس

افزونه فارسی و راست‌چین برای نمایش پیش‌نمایش STL، انتخاب گزینه‌ها، اعمال ضریب اندازه و ثبت قیمت معتبر در سبد خرید ووکامرس.

## نصب

1. پوشه افزونه را در `wp-content/plugins/ordered-3d-print` قرار دهید.
2. ووکامرس را نصب و فعال کنید.
3. افزونه **Ordered 3D Print Configurator** را از پیشخوان وردپرس فعال کنید.

## راه‌اندازی

1. از منوی ووکامرس، یک **قالب گزینه‌ها** ایجاد کنید. نمونه JSON در ویرایشگر قالب قرار داده شده است. قیمت افزوده هر انتخاب باید عددی نامنفی باشد.
2. محصول ساده ووکامرس را ویرایش کنید و پیکربندی چاپ سه‌بعدی را فعال کنید.
3. ابعاد اصلی مدل، حداکثر ابعاد چاپگر، محدوده اندازه و روش قیمت‌گذاری را تعیین کنید. قیمت پایه از قیمت محصول ووکامرس خوانده می‌شود.
4. در صورت نیاز نشانی یک فایل STL را برای پیش‌نمایش وارد کنید.
5. قالب گزینه‌های منتشرشده را به محصول متصل و محصول را ذخیره کنید.

قیمت نهایی در PHP از قیمت محصول و تنظیمات ذخیره‌شده محاسبه می‌شود؛ قیمت ارسالی مرورگر پذیرفته نمی‌شود. حالت حجمی از حجم جعبه محدودکننده بر حسب سانتی‌متر مکعب استفاده می‌کند، نه حجم واقعی هندسی مدل.

## محدوده نسخه نخست

- محصول ساده و فرم افزودن به سبد خرید کلاسیک ووکامرس.
- انتخاب‌های قالب از نوع فهرست کشویی؛ هر محصول می‌تواند یک قالب را استفاده کند.
- پیش‌نمایش STL محلی در مرورگر، با چرخش و بزرگ‌نمایی.
- قیمت پایه ثابت یا قیمت پایه به‌علاوه هزینه حجمی و افزوده گزینه‌ها.
- نگهداری ضریب اندازه، ابعاد و انتخاب‌ها در سبد و سفارش.

بارگذاری فایل توسط مشتری، محاسبه حجم دقیق مش، فایل‌های GLB/OBJ، محصولات متغیر و سازگاری کامل با بلوک‌های سبد و پرداخت در این نسخه پیاده‌سازی نشده‌اند. فایل‌های STL بسیار بزرگ یا پیچیده ممکن است برای نمایش مناسب نباشند. برای استفاده عملی، نسخه ووکامرس و قالب فروشگاه خود را روی محیط آزمایشی بررسی کنید.
